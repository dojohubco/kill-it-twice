Preserve primary failures across best-effort migration/process/sanitization/finalization cleanup. Track evidence/summary/bundle generation, sanitize public summaries and retained local logs.

## Development findings

F03 healthy controls reproduced exit 72 at both original barriers after an ordinary success. Replacement children run the production Source owner, distinguish intentional disconnect, and close their session before orphan exit 72. Both kills, healthy controls and orphans passed in developmental run `m1-20260916180158790-46d3395b` (21/21). Earlier failed runs remain retained. Existing kill/release close-event checks are retained. This new-test correction is explicit; it does not treat an orphan as a SIGKILL.

Output capture has an explicit 1 MiB combined limit and fails on overflow. Owned-group cleanup cannot cover descendants deliberately escaping that group.
