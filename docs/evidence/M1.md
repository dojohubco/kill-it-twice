## Implementation and chronological changes

Only three source tables exist: persisted epoch singleton, entities and immutable outbox. Two allowlisted mutation functions lock lifecycle decisions with FOR UPDATE; triggers generate metadata and same-transaction after-images. Runtime direct writes, metadata/sequence edits, capture bypass, physical removal and role escalation are denied. Privileged functions have a fixed `pg_catalog, pg_temp` search path, qualified objects, no dynamic SQL, non-superuser ownership and revoked PUBLIC EXECUTE. Enforcement details were recorded in docs/milestones/M1.md before migration execution.

Live payloads are JSONB objects; JSONB equality defines no-op. IDs/versions use checked decimal strings; timestamp/payload text avoids implicit driver precision loss. Versions are bounded positive signed BIGINTs. Multi-statement transactions stay on one client, and a COMMIT error is conservatively unknown without automatic retry. Private fault support is confined to tests/. The harness has bounded waits, owned process groups, one pinned service and scoped cleanup.
